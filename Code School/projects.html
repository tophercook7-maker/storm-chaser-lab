A function that encodes a real rule


is_severe() is a tool that holds an actual federal definition. That 1.00-inch hail line
isn't made up — it's the legal threshold for a Severe Thunderstorm Warning. You've turned a rule from
the rulebook into code that applies it, automatically, to real data. That's the whole job in one
function.

WHERE THIS GOESFrom a browser to the real thing


You just did real data science — read stored data, applied a rule, drew a chart. Here's
the honest next rung.



The same code, on the real computer


Install Python (see the last lesson of Code School), then
pip install matplotlib pandas. Everything you wrote here runs there, unchanged — except now
it can read the .csv file your Chase Log exports, save charts as image files, and handle years of
data instead of a browser's worth.



The three that turn this into meteorology


pandas loads your exported log as a spreadsheet you can query. MetPy computes
the real weather math (CAPE, dewpoint, the Skew-T). siphon pulls live NWS data straight into
your program. Chain them and your severe-day scanner becomes a program that reads the actual atmosphere
over your town and charts it. That's not a someday thing — that's your next winter.



And the hardware


The Gear Bench weather station (a Raspberry Pi + a $5 sensor)
produces its own stream of temperature, pressure, and humidity — as Python numbers. Plot those with what
you learned today and you're reading your own instruments. Keyboard to sensor to chart. That loop
is the craft.
