LESSON 02Variables — giving numbers a name


A variable is a labeled box you put a value in. You make one with
name = value. After that, the name stands for the value everywhere you use it. Real
weather code is nothing but hundreds of these — temperature, dewpoint, pressure, wind — each in
its own named box.



The = is not "equals"


In math, = means "these are the same." In code it means "put this into that box."
temp = 88 means "put 88 in the box called temp." You can put a new value in the same box
later, and the old one is just gone.

LESSON 03Numbers & math — the converter


Python does math with + - * / (that star is "times," that slash is "divide").
The rest of the world measures temperature in Celsius; American weather uses Fahrenheit. A
meteorologist converts between them constantly. Let's make the machine do it.



The formula


Fahrenheit = Celsius × 9 / 5 + 32. In Python that's almost the same line.



▶ Try it



  
Python
    

  
  





Order matters — just like math class


Python does * and / before + and -, same as you
learned. If you ever need to force an order, wrap it in parentheses: (a + b) * c.



Your lab


Write the reverse: start from fahrenheit = 100 and compute Celsius. The formula
is Celsius = (Fahrenheit − 32) × 5 / 9. You'll need parentheses. Print it.



Challenge — dewpoint depression


Make temp = 88 and dewpoint = 71, then compute and print
temp - dewpoint. That number, the "dewpoint depression," tells a forecaster how close
the air is to saturating. A small depression on a hot day is storm fuel.










LESSON 04Text & f-strings — building the report


You'll want to mix words and numbers into one clean line — a real report reads
"Hot Springs: 88°F, dewpoint 71°F." The tool for that is the f-string: put an
f right before the opening quote, then drop any variable inside { }.



▶ Try it

Why this beats commas


With an f-string you control every space, comma, and symbol — no surprises. It's how
almost all modern Python builds text, and you'll see it everywhere. Anything inside the curly
braces gets computed: {temp - dewpoint} works too.



Your lab


Build a one-line report that also includes the dewpoint depression, like:
Hot Springs: 88F / DP 71F / spread 17. Put the math right inside the braces.



Challenge


Round a messy number. Try f"{29.92341:.2f}" — the :.2f means "two decimal
places." Print a pressure that way.










LESSON 05if / elif / else — the machine decides


This is where code stops being a calculator and starts being a spotter. An
if statement checks whether something is true and only runs its block if it is. That's
how the Storm Deck decides when to sound the tornado alarm — a comparison, exactly like the ones
you're about to write.



Comparisons give you True or False


> greater, < less, >= at least, == equal
(two equals signs — one is "put in the box," two is "is it equal?"). The if runs its
indented block only when the answer is True. Indentation is not decoration in Python — it's how
the language knows what's inside the if. Four spaces.

LESSON 06Lists — a whole week of weather


One temperature is a variable. Seven of them is a list. A list holds many values
in order, inside square brackets. Every stream of weather data — a week of highs, an hour of radar
scans, a day of pressure readings — is a list.

Counting starts at zero


highs[0] is the first item, highs[1] the second. This trips up
everyone at first — computers count from 0. len() gives how many items, max()
and min() find the biggest and smallest for free.



Your lab

for loop runs the same block once for each item in a list. This is the real power of

The loop set h to each high in turn — 88, then 91, then 94… — and ran the indented

A while loop runs as long as something stays true. Try:

LESSON 09Dictionaries — a real observation


A list is values in order. A dictionary is values with labels — exactly how
real weather data arrives. When the Storm Deck asks the National Weather Service for conditions, it
gets back a dictionary: "temperature" → 88, "dewpoint" → 71, and so on. This
is the shape of live data.

Look things up by name, not by number


With a list you'd have to remember that position 2 is the dewpoint. With a dictionary you just ask
for obs["dewpoint"]. When you pull real data in the next lesson of your life — from the
NWS, from your own weather station — it comes exactly like this.

WHAT COMES NEXTFrom this page to the real tools


The Python you just learned is the same Python the pros use — you were running the
real thing, not a training-wheels copy. The only difference is that they run it on the computer
itself, with extra libraries bolted on. Here's the honest path from here.



1 · Put Python on the actual computer


Go to python.org and download it (free, forever). On Windows, check the box that says
"Add Python to PATH" during install — that one checkbox saves hours. Then you can write
programs that save files, read your Chase Log, and run without a browser.



The tool that installs other tools


Python comes with pip. In a terminal, pip install thing downloads a
library. That's how you add the weather superpowers below.



2 · The real meteorology libraries



  
LibraryWhat it gives you

  
numpyFast math on huge piles of numbers — the base everything sits on.

  
matplotlibTurns your data into charts. Your first plotted temperature graph is a great feeling.

  
pandasSpreadsheets in code. Load a year of readings, ask it questions.

  
MetPyBuilt by meteorologists for meteorologists — dewpoint, CAPE, and the Skew-T sounding chart from the Gear Bench, all as functions.

  
siphonPulls live, real data straight from the National Weather Service into your code.




With MetPy and siphon, the nowcast you just wrote by hand becomes a program
that reads the actual atmosphere over your town, right now. That is a real thing a real 15-year-old
has built.



3 · Point it at hardware


The Gear Bench shows how to build a weather station from a Raspberry Pi and a $5 sensor.
The code that reads that sensor is Python — the same language on this page. Learn it here, wire it
to real instruments there. That loop, from your keyboard to the actual sky, is the entire craft.



The one that decides everything


Read The Long Game if you haven't. The short version: being a real meteorologist is gated
behind math — calculus, then differential equations. Code is how you'll use that math,
and starting now gives you a running head start most people never get. Keep coding. And get into the
most advanced math class your school offers, and stay in it.
